# Voice Of Hands 🤟

**Voice Of Hands** is an inclusive communication system designed to bridge the gap between **deaf/mute individuals and hearing people** using **sign language recognition**, **web technologies**, and **hardware integration**.

The system converts hand signs into readable text and speech, enabling real-time, two-way communication.

---

## 🚀 Project Overview

Communication barriers often limit interaction between deaf individuals and the hearing population.  
**Voice Of Hands** solves this by:

- Recognizing **hand signs using computer vision**
- Converting them into **text and voice**
- Providing a **web-based interface**
- Supporting **hardware-based input** for future scalability
